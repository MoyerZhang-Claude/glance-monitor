Glance 硬件监控悬浮窗 —— 使用说明
==================================

【启动】
双击 Glance.exe。第一次会弹出管理员权限确认，点“是”。
（读取 CPU 温度、功耗和统计帧率都需要管理员权限。）

启动后：
- 屏幕左上角出现半透明数据窗口（游戏里、桌面上都会显示，鼠标会直接穿透）
- 任务栏右下角的托盘图标显示 CPU 温度
  · 鼠标停在图标上：弹出完整数据卡片
  · 左键单击：打开设置
  · 右键单击：菜单（显示/隐藏、调整位置、开机自启、退出）

【快捷键（可在设置里修改）】
Ctrl + Alt + H    显示 / 隐藏悬浮窗
Ctrl + Alt + M    进入拖动模式：直接拖动悬浮窗，双击或再按一次锁定

【开机自启】
设置 → 常规 → 开机自动启动。通过 Windows 计划任务实现，开机不会弹管理员确认。

【文件】
Glance.exe    程序本体（单文件，不需要安装任何运行库）
Glance.json   你的设置（自动生成，可复制到别的电脑）
glance.log    运行日志（出问题时看这里）

【常见问题】
1. 游戏里看不到悬浮窗？
   极少数老游戏使用“独占全屏”，任何外挂式悬浮窗都显示不了。把游戏的显示模式改成
   “无边框窗口 / Borderless”即可。2077、地平线、巫师 3、荒野大镖客 2 都没问题。

2. 会不会影响帧率 / 被反作弊误判？
   Glance 不注入游戏进程，只是一个透明的置顶窗口；帧率通过 Windows 自带的事件统计。
   每秒刷新一次，CPU 占用接近 0。

3. 显卡显示“休眠”？
   笔记本独显空闲时会断电省电，Glance 不会去唤醒它。开始游戏后会自动显示数据。

4. 供电温度（VRM）不显示？
   这项数据只有部分台式机主板提供，笔记本通常没有，读不到时会自动隐藏。

5. 帧率行在桌面上不显示？
   这是正常的：只在前台程序真正渲染画面（比如游戏）时才显示。浏览器、聊天软件等
   默认不统计，名单可以在 设置 → 常规 → 不统计帧率的程序 里修改。

【卸载】
设置 → 常规 → 关闭“开机自动启动”，然后退出程序，删除整个文件夹即可。

---
CPU 传感器通过 PawnIO 驱动读取（模块来自 namazso/PawnIO.Modules，LGPL-2.1）。
帧率统计的事件定义参考了 Intel PresentMon（MIT）。
